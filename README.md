# Mobile Port Check - MySQL Project

## 📱 Project Description

Mobile Port Check is a beginner-level MySQL database project used to store and manage mobile number, network, customer, porting, and SIM status information.

This project demonstrates basic and intermediate SQL queries and database operations.

## 🛠️ Technologies Used

- MySQL
- SQL
- MySQL Workbench

## 🗄️ Database

Database Name:

`mobileportcheck`

Table Name:

`user1`

## 📋 Table Details

| Column | Data Type |
|---|---|
| Mobile_Number | BIGINT |
| Network | CHAR(6) |
| Customer_Name | VARCHAR(30) |
| Aadhar_Number | BIGINT |
| Port | INT |
| Sim_Status | CHAR(8) |

## 🔍 SQL Concepts Used

- CREATE DATABASE
- USE
- CREATE TABLE
- INSERT INTO
- SELECT
- WHERE
- CASE statement
- ORDER BY
- COUNT()
- LIKE
- ROW_NUMBER()
- PARTITION BY

## ✨ Project Features

- Store customer mobile details
- Store network information
- Store customer information
- Track SIM status
- Identify mobile port direction
- Search customers using Aadhaar number
- Filter customers based on port value
- Sort customers alphabetically
- Count records
- Use ROW_NUMBER() window function
